01 DOMAIN

Project Scope

An overview of the research focus, problem, and objectives.

01

Literature Survey

Existing IoT irrigation systems effectively capture isolated environmental parameters but lack a cohesive architecture that unites edge-computed indices with resilient networking. Previous works utilizing ultrasonic sensors for physical blockages rely on isolated threshold alarms without integrating turbidity or flow metrics. Furthermore, prior water quality monitoring solutions depend heavily on cloud infrastructure and centralized validation rather than outputting actionable indices directly at the edge. Existing networking approaches often employ LoRa or 3G star topologies that struggle with line-of-sight constraints and high power consumption, while multi-hop alternatives tend to overburden constrained microcontrollers. At the application layer, conventional Web-GIS dashboards introduce high latency and scalability bottlenecks due to stateless HTTP polling.

02

Research Gap

  • Absence of a unified, multi-parameter health scoring system (such as CHI and CWQI) that operates autonomously at the edge without cloud dependency.
  • Heavy reliance on stable cloud connections in rural areas, rendering critical safety outputs unavailable during frequent network outages.
  • Inefficient networking topologies that either overburden edge nodes with complex mesh routing or suffer from signal degradation and packet collisions in rural settings.
  • Lack of predictive backend analytics, with current platforms relying on simple threshold alerts rather than proactively anticipating infrastructure degradation.
  • High latency and redundant network calls in existing IoT web dashboards caused by stateless HTTP polling.
03

Research Problem

Irrigation canals frequently suffer from siltation and pollution that degrade crop productivity, yet existing automated IoT monitoring systems fail in rural regions because they rely heavily on constant cloud connectivity, lack proactive predictive capabilities, and struggle with high packet collisions over Low-Power Wide-Area Networks.

04

Main Objective

To develop an edge-computing-based Canal Health Monitoring System that utilizes a decentralized communication framework to compute actionable health indices locally and provides a real-time, off-grid decision-support platform for proactive irrigation management.

05

Sub Objectives

  • To engineer localized edge-computing nodes (Health and Quality Sensing Nodes) using ESP32 microcontrollers to autonomously compute a Canal Health Index (CHI) and Canal Water Quality Index (CWQI).
  • To design an edge data aggregation module that bridges localized Wi-Fi (ESP-NOW) with a LoRa backhaul to minimize remote node computational overhead and prevent radio collisions.
  • To implement a Multi-Criteria Decision Analysis (MCDA) algorithm at a centralized gateway to dynamically evaluate mesh network link quality using RSSI, SNR, and packet loss.
  • To build an interactive, event-driven AWS serverless web dashboard that visualizes aggregated telemetry with sub-second latency.
  • To integrate a Random Forest machine learning model within the cloud infrastructure to proactively predict system health and infrastructure bottlenecks before they cause critical system failure.

Methodology

The methodology includes edge-based sensor data acquisition, dual-protocol network aggregation, secure cloud ingestion, and machine learning-driven visualization.

01

Health Index Computation (CHI)

The Health Sensing Node normalizes ultrasonic sludge, flow, and turbidity sensor data into 0-100 scores to locally compute the Canal Health Index (CHI) directly on the ESP32 microcontroller.

02

Quality Index Computation (CWQI)

The Quality Sensing Node filters pH, EC, and temperature data to compute the Canal Water Quality Index (CWQI) and classifies the contamination type (Organic, Chemical, or Mixed) autonomously at the edge.

03

Local Data Ingestion

To prevent local radio collisions and minimize overhead, the sensing nodes transmit their computed indices and metrics to solar-powered field gateways using the connectionless ESP-NOW protocol.

04

LoRa Mesh Transmission

The field gateways utilize Ai-Thinker Ra-02 (SX1278) LoRa transceivers to transmit the aggregated data payloads across a strict linear mesh network optimized for long-range, line-of-sight propagation along the canals.

05

Network Link Evaluation

A centralized Raspberry Pi base station uses a Multi-Criteria Decision Analysis (MCDA) algorithm to dynamically evaluate mesh network links by scoring RSSI, SNR, and packet loss to calculate the Global Mesh Quality.

06

Secure Cloud Ingestion

The base station merges the canal sensor metrics with the network health data into a consolidated JSON payload and transmits it securely via TLS 1.2-encrypted MQTT to AWS IoT Core.

07

Serverless Data Processing

AWS IoT Core routes the incoming telemetry into Amazon DynamoDB for storage, integrating with event-driven AWS Lambda functions to handle backend processing and system scalability.

08

Infrastructure Health Prediction

A deployed 100-estimator Random Forest model processes real-time cloud telemetry via a Flask API on AWS Lightsail to proactively predict system degradation across five operational states.

09

Real-Time Dashboard Visualization

A React.js and Tailwind CSS web dashboard visualizes the telemetry, CHI/CWQI metrics, and geospatial tracking with sub-second latency using AWS API Gateway WebSockets.

Four Core System Components

The architectural framework combines edge intelligence with resilient networking and predictive cloud analytics to support continuous, off-grid irrigation management.

CHI

Canal Health Index

Focuses on physical blockages and capacity loss by autonomously fusing ultrasonic sludge depth, volumetric flow rate, and optical turbidity metrics directly at the edge.

CWQI

Water Quality Index

Focuses on detecting organic and chemical contamination by computing real-time actionable indices from localized pH, electrical conductivity, and temperature sensor data.

MESH

Edge Data Aggregation

Focuses on resilient rural communication, utilizing a hybrid ESP-NOW and LoRa backhaul that is dynamically optimized by a Multi-Criteria Decision Analysis (MCDA) algorithm.

ANALYTICS

Predictive Cloud Dashboard

Focuses on proactive infrastructure monitoring and visualization using an event-driven AWS serverless backend paired with a Random Forest machine learning classifier.
